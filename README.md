# 🐱 猫病诊断治疗系统

基于加权匹配算法的猫咪疾病智能诊断系统，根据症状体征匹配可能的疾病并给出治疗方案。

## ✨ 功能特色

- **24种常见猫病**知识库，覆盖消化道、呼吸道、泌尿系统、皮肤等8大分类
- **69个症状**精细化分类，支持搜索与多选
- **21种猫品种**特异性支持，品种易感疾病自动加权
- **完整治疗方案**：药物治疗、饮食建议、日常护理、就医紧急度
- **精美深色主题**界面，玻璃态效果

## 🚀 在线访问

部署完成后可访问：[Render 在线地址](https://cat-diagnosis.onrender.com)

## 🏠 本地运行

```bash
# 安装依赖
uv sync

# 启动服务
uv run python start.py

# 访问 http://127.0.0.1:8000
```

## 🧪 运行测试

```bash
uv run python -m pytest tests/test_breeds.py -v
```
